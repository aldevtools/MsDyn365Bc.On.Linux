ARCHIVED EXPERIMENT — DO NOT SUBMIT UPSTREAM.

Prototype patch against FEX-Emu (built from source at the 2608 tag) that ports
upstream's Windows-only "interrupt only at block entries" mitigation to Linux,
env-gated behind FEX_PRECISE_ASYNC_SIGNALS so one binary is its own control.

RESULT: it does not fix the bug. Minimal CoreCLR reproducer scored 0/10 with the
knob off and 0/8 with it on, while tracing confirmed the mechanism fired (27
deferrals, 57 deliveries in one run). Reason: classifying 32 SIGRTMIN arrivals
in a failing run put only 11 (34%) in JIT code — 14 elsewhere in FEX host code,
4 in a guest syscall, 3 in FEX's dispatcher. A block-entry gate covers a third,
and one bad suspension corrupts the heap.

Kept because the instrumentation approach (classifying signal arrival sites) is
the reusable part and is what a real fix would need to start from. See
docs/FEX-FIX-FEASIBILITY.md for the full analysis and code locations.

NOT for upstream submission: FEX's CONTRIBUTING.md bans AI-generated code. The
arrival-site distribution is the part with upstream value and a human should
re-derive it independently.

+// PROTOTYPE: When enabled, asynchronous signals that arrive while the thread is executing inside a
+// JIT code buffer are deferred until the JIT reaches the next pending-interrupt check, which is only
+// emitted at block entries and loop back-edges. This matches the WOW64 suspend design, where the
+// comment in Source/Windows/WOW64/Module.cpp states that "interrupts only happen at the start of
+// blocks, [so] the reconstructed state should be entirely accurate".
+//
+// Without this, an async signal is delivered at an arbitrary host PC in the middle of a translated
+// guest instruction, and the guest ucontext FEX synthesises holds a RIP reconstructed to the start of
+// that guest instruction while the SRA registers already hold partially-updated results. A guest that
+// rewrites RIP in that ucontext (CoreCLR activation injection, Go async preemption) then resumes from
+// state that never existed architecturally.
+static bool PreciseAsyncSignalsTrace() {
+  static const bool Enabled = [] {
+    const char* Env = getenv("FEX_PRECISE_ASYNC_SIGNALS_TRACE");
+    return Env && Env[0] != '0';
+  }();
+  return Enabled;
+}
